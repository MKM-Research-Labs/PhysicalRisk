\mkmexecsummary
% =========================================================================

This document benchmarks the Mortgage Pricing Model (MKM-MP-001), which values a
flood-exposed residential mortgage from its amortisation schedule, an
affordability-based credit spread and a loss given default. Version~0.1 tested the
pricer against model document v1.1 and found that the fair value counted the expected
loss twice and took the recovery a month late. Both are fixed in the pricer, and the
document is corrected as v1.3, which this version tests.

\paragraph{The code computes its documented formulae.} Over \bmCases{} loans ---
loan-to-value 0.5 to 1.0, recovery haircuts 0 to 40\%, two incomes, two coupons,
three terms, discounted at the coupon and at a risk-free rate --- the payment, spread,
expected cashflows, expected losses and fair value agree with a 50-digit
implementation of v1.3's Eqs.~1--24 to \bmCodeErr. \bmWolframConfirms

\paragraph{The fair value counts each loss once.} The fair value is now the present
value of the expected cashflows, whose recovery is already net of the loss, and it
equals Wolfram's independent pathwise valuation: the expectation, over the month of
default, of the payments made before it and the recovery made in it. The loss is
taken on the balance owed when the month of default began, so the lender never
recovers more than the property fetches. The correction raises fair value on the
\bmCorrectionShare\% of loans in the grid that carry a loss given default, by up to
\bmCorrection\% of par: a GBP~\bmWorstLoan{} loan that v1.1 valued at
GBP~\bmWorstOld{} is worth GBP~\bmWorstNew{} (Table~\ref{tab:bm-correction}).
Expected loss itself is reported as before, now on the opening balance.

\paragraph{The document's claims hold} (Table~\ref{tab:bm-claims}). v1.3 corrects
those v0.1 found wrong: a 100\,bp rise raises a 25-year payment by
\bmPayLow--\bmPayHigh\%, within the 8--12\% now stated; missing income prices at the
top of the spread schedule (\bmZeroIncome\% at the baseline), as now stated, the
15\% fallback being unreachable; and discounting is described as production does it,
at the risk-free rate the loan calculator supplies. Table~7 is reproduced exactly,
the expected-loss bound holds, and Wolfram proves the par identity symbolically.

(Table~\ref{tab:bm-checks}).

\mkmframework
% =========================================================================

Following the document (v1.3, \S3): monthly payment $M$, balances $B_0,\dots,B_n$,
monthly default probability $h=1-e^{-s/12}$, survival $S_i=(1-h)^i$,
$\mathrm{PD}_i=S_{i-1}-S_i$, recoverable value $R=(1-\delta)V$, discount factors $D_i$,
and the loss on a default in month $i$ taken on the balance owed when the month began,
$\mathrm{LGD}_i=\max(0,B_{i-1}-R)$. Then
\begin{equation}
\mathrm{FV}=\mathrm{PV}_{\mathrm{CF}}=\sum_i D_i\bigl[M S_i+(B_{i-1}-\mathrm{LGD}_i)\,\mathrm{PD}_i\bigr],
\qquad
\mathrm{PV}_{\mathrm{EL}}=\sum_i D_i\,\mathrm{LGD}_i\,\mathrm{PD}_i,
\end{equation}
with $B_{i-1}-\mathrm{LGD}_i=\min(B_{i-1},R)$, the recovery.

\paragraph{The pathwise value.} Let $\tau$ be the month of default, so that
$P(\tau=i)=\mathrm{PD}_i$ and $P(\tau>n)=S_n$. On the path where it defaults in month
$\tau$, the lender receives $M$ in each month before $\tau$ and $\min(B_{\tau-1},R)$
in month $\tau$; on the path where it never defaults, all $n$ payments. Taking the
expectation,
\begin{equation}
\mathbb{E}[\mathrm{PV}]=\sum_{i=1}^n D_i\bigl[M\,P(\tau>i)+\min(B_{i-1},R)\,P(\tau=i)\bigr]
=\mathrm{PV}_{\mathrm{CF}}.
\end{equation}

\paragraph{What v1.1 did.} v1.1 took the loss on the closing balance,
$\max(0,B_i-R)$, so its recovery $R+(B_{i-1}-B_i)$ exceeded $R$ by a month's principal
when the loan was under water; and it set $\mathrm{FV}=\mathrm{PV}_{\mathrm{CF}}-\mathrm{PV}_{\mathrm{EL}}$,
deducting a loss already inside the recovery.

\section{Benchmark Method}
% =========================================================================

The equations above are evaluated with \texttt{mpmath} at 50 significant digits, from
v1.3 of the document rather than the code; the loan-to-value ratio is taken as the double the
code compares against its bands, since a band edge such as 0.95 falls between the
exact ratio and its double. Wolfram evaluates, from each input's exact value at
60-digit precision, both the document's fair value and the pathwise value, the
latter as an expectation over a \texttt{GeometricDistribution} default month with the
payments' present values accumulated, and it proves symbolically that the
contractual payments discounted at the coupon are worth par.

\begin{enumerate}[leftmargin=*]
\item \textbf{Benchmark, not validation.} The code is shown to compute its documented
  formulae, and the fair value to be the expectation of the lender's cashflows under
  the model's default process; whether an affordability-based spread is the right
  default process is a separate question.
\item \textbf{Downstream.} Every fair value with a loss given default rises, and with
  it the portfolio totals and the discount to par that consume it; figures produced
  before the fix are understated by up to the amounts above.
\item \textbf{Discounting.} At the risk-free rate the loan calculator supplies, a
  coupon above it values the loan above par, so the discount to par measures the
  coupon's margin as well as credit (v1.3, \S5.3).
\end{enumerate}
