\mkmexecsummary

\textit{Skeleton document — content to be filled out as the model matures
through Phase 1 of the implementation plan
(\texttt{src/models/typhoon/phase\_1\_plan.md}).}

The Tropical Cyclone Progression and Wind-Field Model (\texttt{MKM-TC-001})
simulates the forward motion, intensity evolution, and local wind field of
tropical cyclones (typhoons) for catchments exposed to TC hazard. It combines:

\begin{itemize}
  \item A Bayesian state-space progression engine, advancing a latent storm
        state through time with regime-conditioned motion, intensity, and size
        transitions.
  \item A Sequential Monte Carlo (particle filter) inference layer.
  \item A parametric radial wind-field with motion-linked asymmetry, surface
        reduction, and configurable inner-core and outer-decay structure.
\end{itemize}

The model is catchment-agnostic. Catchment-specific calibration is supplied
through \texttt{config.typhoon} parameter dataclasses, populated by each
catchment's \texttt{data/catch/<id>/tc.py} file.

\textbf{Status:} Development. Phase 1.1 (data structures and parameter schema)
delivered as of the document date. Phases 1.2 through 1.8 in progress.

\textbf{Key risk:} Phase 1 uses placeholder calibration. The model is not
approved for production use until Phase 3 historical calibration completes
and the Model Risk Committee (MRC) issues approval.

\section{Mathematical Framework}

\subsection{Latent State}

The latent storm state at time $t$ is
\[
s_t = (\lambda_t, \phi_t, u_t, \psi_t, V_t, R_{\max,t}, R_{\text{outer},t}, k_t),
\]
where $\lambda, \phi$ are longitude and latitude, $u$ is translation speed,
$\psi$ is heading, $V$ is maximum sustained wind, $R_{\max}$ and $R_{\text{outer}}$
are the radii of maximum wind and the outer (gale-force) wind, and $k$ is a
discrete regime class.

\subsection{Storm-Coupled Genesis (Wind-into-PRS)}
\label{sec:coupled_genesis}

When invoked as part of the coupled storm--typhoon event set for PRS pricing,
genesis is no longer drawn independently. Each typhoon is paired 1:1 with a
storm sequence sharing an \texttt{event\_id}, and the genesis peak wind is
\emph{conditioned} on that storm's meteorological severity. The full coupling
specification (motivation, calibration, validation criteria) lives in
\texttt{docs/models/storm\_typhoon\_coupling/coupling\_spec.md}; this subsection
records the genesis-layer realisation in \texttt{src/models/typhoon/genesis.py}.

Let $z$ be the paired storm's severity latent (\texttt{base\_intensity}) and
$q \in (0,1)$ its empirical severity quantile across the $N$-event batch,
$q_i = \operatorname{rank}(z_i)/(N+1)$. The event's wind strength percentile
$\rho_w$ is drawn within a $q$-dependent band:
\begin{align}
    \text{floor}(q) &= 1 - (1-q)^{\beta}, &
    \text{ceiling}(q) &= q, \\
    \rho_w &= \text{floor}(q) + B\,[\,q - \text{floor}(q)\,], & B &\sim \mathrm{Uniform}[0,1],
\end{align}
and the genesis peak wind is recovered by inverting the scenario-mix-weighted
catchment wind-exceedance curve, $V_{\max} = S_{\text{cat}}^{-1}(1-\rho_w)$
(\texttt{coupled\_genesis\_wind}, using \texttt{coupling\_floor},
\texttt{mixture\_peak\_wind\_exceedance}, and \texttt{mixture\_peak\_wind\_inverse}).
The coupling is \textbf{directed and asymmetric}: wind can never rank above the
storm ($\rho_w \le q$, forbidding high-wind/low-rain), but a rising floor pulls
the wind up in the storm tail. The single parameter $\beta$ tunes the strength
($\beta \to 0$ pure ceiling, $\beta = 1$ comonotone; interim $\beta \approx 0.52$
matching expert anchors), shipped as \texttt{config.port.COUPLING\_BETA} with a
\texttt{--coupling-beta} override.

Within an event the coupled $V_{\max}$ (and its derived scenario family)
\textbf{override} the genesis draw for all particles, so the whole SMC ensemble
starts from the one coupled intensity while still exploring track, size,
location, and regime; \texttt{step()} subsequently evolves $V_{\max}$ so
trajectory diversity persists. The typhoon count is slaved to the storm count
(\texttt{--num-storms}), giving a bijective \texttt{event\_id} pairing.

\textbf{Effect on the wind marginal.} Because winds are gated below the
storm-severity ceiling, the realised marginal distribution of $V_{\max}$ shifts
\emph{downward} relative to the standalone (uncoupled) genesis prior: the
\texttt{tc.py} bands now define the attainable ceiling, not the realised
frequency. This is the deliberate cost of ``rain without wind, but no wind
without rain.'' Catchments without a \texttt{tc.py} produce no wind component
(flood-only fallback).

  \item \texttt{src/models/typhoon/plausibility.py} — simulation-mode
        soft constraints (to be added in Phase 1.5).
  \item \texttt{src/models/typhoon/wind\_field.py} — parametric radial
        wind-field (to be added in Phase 1.6).
  \item \texttt{src/models/typhoon/pipeline.py} — end-to-end orchestration
        (to be added in Phase 1.7).
\end{itemize}

\subsection{Catchment Integration}

The model is catchment-agnostic. The invocation path is:

\begin{verbatim}
MKM_CATCHMENT=<catchment_id> python3 app.py port --typhoon
\end{verbatim}

A thin boundary adapter under
\texttt{app/commands/port/stages/typhoon\_stage.py} reads the active catchment's
\texttt{tc.py} via the config routing layer, assembles a
\texttt{CatchmentTyphoonConfig} dataclass, and calls
\texttt{simulate\_typhoon\_events(...)}. The model never imports from
\texttt{data/catch/*}.

% 8. LIMITATIONS AND ASSUMPTIONS

\section{Limitations and Assumptions}

Refer to entry \texttt{MKM-TC-001} in \texttt{data/model\_inventory.json} for
the canonical list. Phase 1 limitations include:

\begin{itemize}
  \item No historical calibration — parameters are first-pass placeholders.
  \item Land mask is a simple bbox placeholder rather than a true coastline polygon.
  \item No real-observation assimilation in Phase 1 (simulation mode only).
  \item Joint surge/rain hazard layer deferred to Phase 2.
  \item In storm-coupled mode (Section~\ref{sec:coupled_genesis}) the wind
        marginal is conditional and shifts downward versus the standalone prior;
        the coupling strength $\beta$ is a provisional expert prior pending
        calibration.
\end{itemize}
