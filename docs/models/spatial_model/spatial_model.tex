% 1. EXECUTIVE SUMMARY
% ===================================================================
\mkmexecsummary

The Spatial Interpolation Model provides geospatial mapping of river gauge
observations to individual property locations using Inverse Distance Weighting
(IDW). It is a core infrastructure component of the MKM PhysicalRisk platform,
enabling property-level flood depth estimation from sparse gauge networks.

The model constructs a KDTree spatial index over gauge coordinates for efficient
nearest-neighbour queries, then applies IDW interpolation with a configurable
power parameter to produce water surface elevation (WSE) estimates at arbitrary
target locations. A haversine distance function ensures correct great-circle
distance calculations on the Earth's surface.

The model also supports polyline projection (nearest point on a river centreline)
and spatial correlation matrix construction for portfolio-level risk aggregation.

\textbf{Key risk:} IDW assumes smooth spatial variation and does not capture
terrain discontinuities (e.g.\ flood barriers, embankments). Accuracy degrades
rapidly with increasing distance from the nearest gauge.

\mkmpurpose

\subsection{Purpose}

The Spatial Interpolation Model serves three functions:

\begin{itemize}[nosep]
    \item \textbf{Gauge-to-property mapping}: Interpolate flood water surface
          elevation from observed gauge readings to individual property locations.
    \item \textbf{Spatial indexing}: Build efficient KDTree structures for
          nearest-neighbour search over large gauge networks.
    \item \textbf{Portfolio correlation}: Construct spatial correlation matrices
          between properties for aggregated risk calculations.
\end{itemize}

\subsection{Scope}

The model handles:
\begin{itemize}[nosep]
    \item Point-to-point IDW interpolation with configurable power parameter.
    \item KDTree construction from latitude/longitude gauge data.
    \item Haversine great-circle distance calculations.
    \item Nearest point projection onto river polylines.
    \item Exponential distance-decay correlation matrices.
\end{itemize}


% ===================================================================
% 3. METHODOLOGY
% ===================================================================
\section{Methodology}

\subsection{Inverse Distance Weighting}

The IDW estimator at a target point $\mathbf{x}_0$ is:
\begin{equation}
    \hat{z}(\mathbf{x}_0) = \frac{\sum_{i=1}^{n} w_i \, z_i}{\sum_{i=1}^{n} w_i}, \qquad
    w_i = \frac{1}{d(\mathbf{x}_0, \mathbf{x}_i)^p}
\end{equation}
where $z_i$ is the observed value at gauge $i$, $d(\cdot)$ is the haversine
distance, and $p$ is the power parameter (default $p=2$).

If any gauge lies within a minimum distance threshold (default 1\,m), its
value is returned directly without interpolation.

\subsection{Haversine Distance}

Great-circle distance between two points $(\phi_1, \lambda_1)$ and
$(\phi_2, \lambda_2)$:
\begin{equation}
    d = 2R \arctan\!\left(\sqrt{a},\; \sqrt{1-a}\right), \qquad
    a = \sin^2\!\frac{\Delta\phi}{2} + \cos\phi_1 \cos\phi_2 \sin^2\!\frac{\Delta\lambda}{2}
\end{equation}
where $R = 6{,}371{,}000$\,m is the Earth's mean radius.

\subsection{KDTree Spatial Index}

Gauge coordinates are converted to radians and indexed using
\texttt{scipy.spatial.cKDTree} for $O(\log n)$ nearest-neighbour queries.

\subsection{Spatial Correlation}

The correlation between properties $i$ and $j$ decays exponentially with distance:
\begin{equation}
    \rho_{ij} = \rho_0 \exp\!\left(-\frac{d_{ij}}{L}\right)
\end{equation}
where $\rho_0$ is the base correlation and $L$ is the correlation length scale.

\section{Inputs and Outputs}

\subsection{Inputs}
\begin{itemize}[nosep]
    \item Gauge locations: latitude, longitude, elevation (from gauge metadata).
    \item Gauge flood observations: flood depth per gauge for a given event.
    \item Target property location: latitude, longitude, elevation.
    \item IDW power parameter $p$ (default 2.0).
    \item Minimum distance threshold (default 1.0\,m).
    \item Correlation distance and base correlation (for portfolio aggregation).
\end{itemize}

\subsection{Outputs}
\begin{itemize}[nosep]
    \item Interpolated water surface elevation at target location.
    \item Nearest gauge distance and identity.
    \item Spatial correlation matrix (for portfolio risk).
\end{itemize}


% ===================================================================
% 5. ASSUMPTIONS AND LIMITATIONS
% ===================================================================
\section{Assumptions and Limitations}

\subsection{Assumptions}
\begin{enumerate}[nosep]
    \item Flood water surface varies smoothly between gauge locations.
    \item The haversine formula provides sufficient distance accuracy at the
          spatial scales of interest (< 100\,km).
    \item Gauge observations are contemporaneous for a given flood event.
    \item The IDW power parameter is constant across the interpolation domain.
\end{enumerate}

\subsection{Limitations}
\begin{enumerate}[nosep]
    \item IDW cannot model terrain barriers (embankments, levees, ridgelines).
    \item Interpolation quality degrades with sparse gauge networks.
    \item The flat-Earth approximation used in polyline projection introduces
          errors at distances $> 50$\,km.
    \item No anisotropy: the model treats all directions equally, whereas
          flood propagation follows river valleys.
\end{enumerate}

\section{Validation Questions}

\mkmvqitem{1}{Purpose}{Is the model being used for its intended purpose?}
Yes. The model is used exclusively for spatial interpolation of flood observations
from gauge networks to property locations, consistent with its design scope.

\mkmvqitem{2}{Conceptual Soundness}{Is the model conceptually sound?}
IDW is a well-established geostatistical interpolation method. The haversine
distance formula is exact for the Earth's geometry. The KDTree provides
optimal nearest-neighbour search complexity.

\mkmvqitem{3}{Data Quality}{Is the data quality adequate?}
Gauge metadata (coordinates, elevation) is sourced from EA and SEPA official
records. Quality depends on the upstream gauge data pipeline.

\mkmvqitem{4}{Developmental Evidence}{Is there adequate developmental evidence?}
The implementation follows standard scipy spatial algorithms (cKDTree, cdist).
Unit tests verify haversine accuracy, IDW convergence, and KDTree correctness.

\mkmvqitem{5}{Outcomes Analysis}{Are outcomes reasonable?}
Interpolated WSE values are validated against held-out gauge readings and
known flood event observations.

\mkmvqitem{6}{Ongoing Monitoring}{What ongoing monitoring is required?}
Interpolation error should be tracked against actual flood observations.
The power parameter $p$ should be reviewed annually.

\mkmvqitem{7}{Benchmarking}{Has the model been benchmarked?}
IDW results are compared against kriging and nearest-neighbour baselines.

\mkmvqitem{8}{Monitoring}{What type of monitoring is required?}
Quarterly review of interpolation residuals against observed flood depths.
Annual review of gauge network density and spatial coverage.

\mkmvqitem{9}{Overall Risk}{Is the overall model risk acceptable?}
The model is a standard geostatistical tool with well-understood limitations.
Overall risk is Low, provided gauge density is sufficient.
