Chapter 10.1: Flood Model Landscape (pp. 339-347)
================================================================

CORE THESIS
-----------
The modern model landscape is a layered architecture of core engines (computational
workhorses), science engines (hazard/analytics logic), and deployed model instances.
The intellectual content that once differentiated vendors has migrated into the public
domain. The key concept is the CSD model instance taxonomy (Core engine, Science engine,
Deployment context) which explains why model inventories balloon from a few engines to
hundreds of named models -- the combinations multiply combinatorially.

OASIS is positioned as the natural culmination: an open-source framework separating
exposure, hazard, and results into reusable, interoperable components.

KEY ARGUMENTS
-------------
1. Model normalisation is complete: mathematical foundations are now public academic
   material; differentiator is data curation, calibration, and deployment
2. Three-layer architecture: core engines, science engines, deployed instances
3. Six dimensions drive combinatorial explosion: core engine, science engine,
   geography, asset type, financial vehicle, purpose
4. Public foundations dominate: national services maintain reference data and catalogues
5. OASIS embodies the shift from proprietary to shared infrastructure
6. Open models transform markets by lowering barriers and increasing comparability

KEY MODELS AND FRAMEWORKS

- Six dimensions of model deployment
- OASIS Loss Modelling Framework (BSD 3-Clause)

CDS INFRASTRUCTURE ANALOGY
---------------------------
Same layered architecture (core + science + deployment) applies to both derivatives
pricing and catastrophe modelling. PRS sits at the intersection. The CSD taxonomy
means banks can classify PRS alongside existing CDS model instances.
